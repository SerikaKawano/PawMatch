# PawMatch 形成的評価の実施案

目的は実際の譲渡審査時間の短縮を測ることではなく、審査フローの各工程で参加者が必要な情報と次の行動を理解できるか、どこで誤解が生じるかを見つけることである。対象は同意を得た成人5名。保護活動の実務経験の有無を記録し、実務者が含まれなければ実務適合性の検証とは記さない。

## 実施手順

1. 大学の倫理手続を確認し、研究目的、所要時間、記録内容、撤回方法を説明する。認められる方法で口頭またはEメールによる同意を得て、日付・方法・範囲を記録する。
2. 参加者ごとに同じ架空ケース2件を一度ずつ提示する。一方は暫定点が高くても住居確認が未了のケース、もう一方は動物固有の医療・ケア条件を含むケースとする。質問文とケース資料は開始前に固定する。
3. 申込み受付、初期確認、リスク・適合性、書類確認・連絡、面談・トライアル、最終記録の6工程を順に見てもらう。研究者は操作を代行せず、困難や発言を記録する。
4. 各工程で下記3問を1～5点と「該当なし」で回答してもらい、各評価の理由となる具体例を尋ねる。特に低い評価では、どの表示や情報が問題かを確認する。
5. 各ケースで「現時点で不足する証拠は何か」「次に誰へ何を確認するか」「今は先に進めるか」を本人の言葉で説明してもらう。ケース別の重要確認項目との一致を記録するが、実際の譲渡判断の正確さとは呼ばない。
6. 最後に「不要に感じた工程」「点数や警告が誤解を招いた箇所」「不足する情報」「最も役立った工程」を半構造化面接で尋ねる。誘導質問は避ける。

## 工程ごとの質問

1. この工程の目的と現在の状態は分かりましたか。
2. 示された情報は、次の対応を考えるのに役立ちましたか。
3. 何がまだ未確認かを理解できた自信はありますか。

尺度は1「全くそう思わない」、2「あまりそう思わない」、3「どちらともいえない」、4「ややそう思う」、5「強くそう思う」。該当なし・無回答は0点にせず、分母から区別する。自信の高さを正答とみなさず、ケース課題での説明と照合する。

## 分析と報告

工程×参加者の回答表を作り、各設問の有効回答数と1～5点の分布を示す。5人の平均値だけにまとめない。自由記述・観察は「理解できた」「証拠が不足」「表示が誤解を招く」「手順が不要」「その他」に分類し、反対意見も残す。変更案ごとに、対応する発言または観察記録を示す。参加者の引用には別途許可を得る。実務の審査時間、譲渡率、動物福祉の改善をこのテストから推定しない。

## 方法の根拠

- [GOV.UKの質的ユーザビリティテスト指針](https://www.gov.uk/guidance/usability-testing-qualitative-studies)：5～6名、具体的な課題、行動観察と振り返りを推奨。
- [GOV.UKのサービス全体のベンチマーク指針](https://www.gov.uk/service-manual/measuring-success/usability-benchmarking-a-website-or-whole-service)：定量的なサービス比較には30～60名の実利用者・利用見込み者を想定。本研究の5名はこの用途ではない。
